# 💣 BomberLAN - ボンバーマン風 LAN マルチプレイヤーゲーム

同じローカルネットワーク（LAN/Wi-Fi）内のプレイヤー同士で手軽にブラウザから遊べる、ボンバーマン風のリアルタイムマルチプレイヤーゲームです。

ホストPCがサーバーを起動するだけで、LAN内のスマホや他PCは**表示されたQRコードをスキャンするか共有リンクを開くだけ**で即座に参加できます（アプリのインストール等は一切不要）。

---

## ✨ 主な特徴と実装仕様

1. **🛡️ チーム対戦モード (2v2 / 3v3 / 個人戦FFA)**
   - **2チーム制（🔵 Team Blue vs 🔴 Team Red）**: 2人チーム（2v2・最大4人）または3人チーム（3v3・最大6人）で対戦可能。
   - **ロビーでの自由なチーム選択**: プレイヤーはワンタップで青チーム・赤チームを選択可能（未選択時はゲーム開始時に自動バランス調整）。
   - **フレンドリーファイア有効**: 爆風は敵だけでなく**味方にも当たります！** チームメイトを巻き込まない立ち回りと戦略的協力が勝敗を分けます。
   - **チームスコア & リアルタイム生存状況**: 画面上部のチーム対戦HUDで各チームのラウンド勝利数および各メンバーの生存/撃破状況をリアルタイム表示。

2. **💖 仲間復活パワー (使い切り蘇生アイテム)**
   - ソフトブロック破壊時に新アイテム「💖 リバイブ」がドロップ。
   - 取得したプレイヤーは倒れた味方を**1度だけ即時蘇生**可能（PC: `Rキー` / スマホ: `💖 REVIVEボタン` / 倒れた仲間の元へ移動）。
   - 蘇生された仲間は**3秒間の無敵バリア（シールド）**を纏って安全に戦線復帰（※パワーは1回使うと消滅）。
   - 聖なるチャイム効果音、光線エフェクト、画面上部トースト通知で復活を劇的に演出！

3. **⚡ 超高負荷対応・超軽量ハイパフォーマンス最適化 (4〜6人同時対戦でもラグなし)**
   - **マップオフスクリーンキャッシュ (1500回→1回の描画コール)**: 静的な床・壁・ブロックをオフスクリーンCanvasにキャッシュ。フレーム毎の描画負荷を10分の1以下に削減し、低スペック端末やスマホでも滑らかな60fps+を維持。
   - **ネットワーク帯域80%削減（デルタ配信）**: 195マスのマップ配列はブロック破壊時のみ配信。通常フレームでは除外し、JSONシリアライズとネットワークパケット詰まりを完全解消。
   - **滑らかな座標補間 (Lerp)**: サーバー配信（30Hz）をクライアント側の `requestAnimationFrame` でモニターのリフレッシュレート（60〜144Hz）に合わせて滑らかに補間移動。

4. **🎨 スタイライズド・キャラクター & 美しいマップテーマ**
   - **丸いだけのボールから可愛いキャラクターへ進化**:
     - 歩行アニメーション（前後に動く足・ブーツ、揺れる腕・白手袋）。
     - 立体的なヘルメット、歩行に合わせて揺れるアンテナポンポン。
     - チーム別スーツアーマー（青チーム: サイバーナイト、赤チーム: クリムゾンニンジャ）。
     - 表情豊かなバイザー、視線追従、自然な瞬き（まばたき）アニメーション。
     - 復活パワー保持時の頭上エンジェルリング、無敵時の半透明ヘックスシールド、撃破時の天使ゴースト。
   - **選べる3種類の美しいマップテーマ**:
     - ⚡ **サイバー・マトリクス (Cyber Matrix)**: ネオングリッド床、チタン柱、ホログラムクレート。
     - 🌿 **古代エメラルド遺跡 (Emerald Ruins)**: コケ生す石畳、エメラルドルーン石柱、木製宝箱。
     - 🌋 **マグマ要塞 (Magma Foundry)**: 溶岩亀裂床、黒曜石柱、灼熱ブラストコンテナ。

5. **⚡ 爆弾キックメカニクス & パワーアップ**
   - キック能力を持つプレイヤーが爆弾に向かって移動すると、障害物に当たるまで爆弾が滑走。
   - 豊富なアイテム：🔥 ファイア、💣 ボム、👟 スピード、⚡ キック、💖 リバイブ。

6. **ホスト・クライアント LAN接続（ゼロインストール）**
   - ターミナルおよびゲーム画面（ロビー）に**接続用QRコード**とURLを自動生成。
   - アプリ不要、ブラウザを開くだけで即対戦開始。

## ☁️ GitHub Codespaces でプレイする場合（重要設定）

GitHub Codespaces 上で起動する場合、デフォルトではポートが **Private（非公開）** になっているため、ホスト本人以外は接続できません。他のプレイヤーがアクセスできるようにするために以下の手順を行ってください：

1. VS Code（Codespaces）下部パネルの **「PORTS（ポート）」** タブを開きます。
2. ポート **`3000`** の行を探します。
3. **「Visibility（可視性）」** 列を右クリック（または地球アイコンをクリック）します。
4. **「Port Visibility」** を **「Public（パブリック）」** に変更します。
5. コンソールまたはロビー画面に表示される **`https://<codespace-name>-3000.app.github.dev/?room=main`** を他のプレイヤーに共有するか、QRコードをスマホでスキャンしてもらえば参加できます！

## 🎮 遊び方

### ローカル（LAN / Wi-Fi）環境の場合
1. **ホストPC:**
   - ブラウザで `http://localhost:3000` を開きます。
   - 名前を入力して「ロビーに入る」をクリックします。
2. **他のプレイヤー（スマホや別PC）:**
   - ホストと同じWi-Fiまたは有線LANに接続します。
   - ホスト画面に表示された**QRコードをスマホのカメラで読み取る**か、表示されたLAN IP付きURL（例: `http://192.168.X.X:3000/?room=main`）にアクセスします。
   - 名前を入力してロビーに入ります（最大8人）。

### ゲームの進行
1. **ゲーム開始:**
   - ホストが「ゲーム開始！」ボタンを押すと全員同時に試合がスタートします。
2. **勝敗:**
   - 最後の1人になるまで生き残ったプレイヤーが勝利！
   - ゲーム終了後、モーダルの「もう一回プレイ！」で何度でも連戦可能です。
